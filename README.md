## 📂 Projects

### 1. 🎓 College Student Dashboard

**Path:** `College_Student_Dashboard/student-dashboard`

A responsive college student dashboard built using **React.js and Vite**.

#### Features

* Student profile
* Student information card
* Attendance details
* Subject list
* Examination details
* Header and footer components
* Component-based React architecture
* Responsive dashboard UI

#### Technologies

* React.js
* Vite
* JavaScript
* HTML5
* CSS3

#### Run Locally

```bash
cd College_Student_Dashboard/student-dashboard

npm install

npm run dev
```

The application will normally be available at:

```text
http://localhost:5173
```

### 4. 👨‍🎓 Student Portal

**Path:** `student_portal/student-portal`

A full-stack Student Portal application implementing user authentication and student profile functionality.

#### Features

* User registration
* User login
* JWT authentication
* Protected routes
* Student profile
* REST API
* MongoDB database integration
* Express.js backend

#### Technologies

* Node.js
* Express.js
* MongoDB
* MongoDB Compass
* JWT
* JavaScript
* HTML/CSS

#### Backend Setup

```bash
cd student_portal/student-portal

npm install
```

Create a `.env` file:

```env
MONGO_URI=mongodb://localhost:27017/student_portal
JWT_SECRET=your_secret_key
PORT=5000
```

Start the server:

```bash
npm start
```

For development:

```bash
npm run dev
```

The backend will normally run on:

```text
http://localhost:5000
```
